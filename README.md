# 🧩 照片滑块拼图

一个纯前端的照片滑块拼图小游戏：照片被打乱成 N×N 的图块，点击空白格旁边的图块，每次移动一格，把照片拼回原样。

单文件实现（`index.html`），零依赖、零构建，打开即玩。

## 在线试玩

启用 GitHub Pages 后访问：`https://<你的用户名>.github.io/photo-sliding-puzzle/`

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

## 玩法

- 🎚️ **三档难度**：3×3 休闲 / 4×4 经典 / 5×5 挑战
- 🔀 **智能打乱**：从完成状态随机游走生成，保证一定有解
- 📷 **换照片**：上传自己的照片，自动裁剪成正方形变成拼图
- 🔢 **数字提示**：卡关时打开角标照着拼
- ⏱️ **数据统计**：步数 + 计时，自动保存各难度最佳纪录（localStorage）
- 🎉 **胜利反馈**：补齐最后一块、彩带庆祝 + 音效
- ⌨️ **键盘支持**：方向键移动图块，手机触屏同样可玩

## 技术要点

- 纯原生 HTML / CSS / JavaScript，无任何第三方依赖
- 图块用 `background-position` 百分比切分图片
- 打乱采用「随机合法移动」算法，天然保证可解性
- 内置默认图片由 Canvas 实时绘制（日落风景）
- 音效用 Web Audio API 合成，彩带用 Canvas 粒子实现
